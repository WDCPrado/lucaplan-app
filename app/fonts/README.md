# Fuentes locales

Archivos variables WOFF2 originales, sin modificar, cargados con `next/font/local`.
El build no consulta Google Fonts; las familias y variables CSS se conservan.

- `Geist.woff2` y `GeistMono.woff2`: [Vercel Geist, commit 2e554ff](https://github.com/vercel/geist-font/tree/2e554ff2ea3979b63afe770af6424eb8b9490a74/fonts), archivos `Geist/webfonts/Geist[wght].woff2` y `GeistMono/webfonts/GeistMono[wght].woff2`. Licencia: `Geist-OFL.txt`.
- `SpaceGrotesk.woff2`: [Space Grotesk, commit 03507d0](https://github.com/floriankarsten/space-grotesk/tree/03507d024a01282884232081fc6011c09ff4e849/fonts/woff2), archivo `SpaceGrotesk[wght].woff2`. Licencia: `SpaceGrotesk-OFL.txt`.
